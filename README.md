# The Light Turns Anyway

A six-line entry for the make.fun bounty "Make the AI judge feel brave". Somewhere a lighthouse keeper is making tea while the storm does what storms do — he watches the kettle, not the weather, because the light has turned by itself every night he was ever afraid, and it will turn tonight too. `main.py` (Python standard library only, no network) writes the text deterministically to `/output/entry.txt`.
